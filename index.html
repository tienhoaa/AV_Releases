                Quản Lý Cặp Khóa Số RSA-2048
              

              
Cặp khóa RSA-2048 bảo vệ toàn vẹn bản quyền. Khóa Riêng Tư (Private Key) được lưu cục bộ trên trình duyệt của bạn.

            

            
            

              
              Chưa nạp Private Key
            

          


          
          

            
            
            

              

                

                  
                

                
Nạp Khóa Mặc Định

                
Nạp cặp khóa tiêu chuẩn hệ thống đã cấu hình sẵn trong thư mục /keys.

              

              
            


            
            

              

                

                  
                

                
Tải Lên Private Key (.pem)

                
Chọn file private_key.pem chuẩn PKCS#8 từ máy tính hoặc điện thoại.

              

              
            


            
            

              

                

                  
                

                
Tạo Cặp Khóa Mới (Web Crypto)

                
Sinh cặp khóa RSA-2048 bit hoàn toàn mới trực tiếp ngay trong trình duyệt.

                  Đồng Bộ Danh Sách Đen Lên GitHub (Online Revocation)
                

                Chính Thức
              

              

                Tự động đẩy danh sách thiết bị bị thu hồi lên file revoked_hwid.json tại repository GitHub tienhoaa/AV_Releases. Plugin Civil 3D sẽ đọc file này qua đường dẫn Raw trực tiếp để khóa thiết bị vi phạm.
              


              

                
                
              


              

                

                  
                  
                

                

                  
                  
                

              


              

                
                

                  
                  
                

                
Yêu cầu quyền repo hoặc contents:write để cập nhật file.

              Mã C# Kiểm Tra Bản Quyền & Blacklist GitHub Trong Civil 3D
            

            

              Plugin Civil 3D kết hợp 2 lớp bảo vệ: (1) Xác thực chữ ký số RSA-2048 offline + (2) Kiểm tra Blacklist trên GitHub:
            


            

              
              
// ========================================================
// 1. XÁC THỰC FILE BẢN QUYỀN OFFLINE (RSA-2048)
// ========================================================
string licPath = @"C:\ProgramData\AV_Civil\AV_License.avlic";
string jsonText = File.ReadAllText(licPath);
var licDoc = JsonDocument.Parse(jsonText);
string payloadString = licDoc.RootElement.GetProperty("payload").GetRawText();
string signatureBase64 = licDoc.RootElement.GetProperty("signature").GetString();

string publicKeyPem = @"-----BEGIN PUBLIC KEY-----
MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEAi9xQ1EpUK+sQCd+zVTAb...
-----END PUBLIC KEY-----";

using (var rsa = RSA.Create())
{
    rsa.ImportFromPem(publicKeyPem);
    byte[] dataBytes = Encoding.UTF8.GetBytes(payloadString);
    byte[] sigBytes = Convert.FromBase64String(signatureBase64);
    
    bool isValid = rsa.VerifyData(dataBytes, sigBytes, 
        HashAlgorithmName.SHA256, RSASignaturePadding.Pkcs1);

    if (!isValid) throw new Exception("Chữ ký bản quyền không hợp lệ!");
}

// ========================================================
// 2. KIỂM TRA THU HỒI ONLINE TỪ GITHUB (ASYNCHRONOUS)
// ========================================================
string currentHwid = GetSystemHwid(); // "AV-XXXX-XXXX-XXXX-XXXX"
string checkUrl = "https://raw.githubusercontent.com/tienhoaa/AV_Releases/main/revoked_hwid.json";

try
{
    using (var client = new HttpClient { Timeout = TimeSpan.FromSeconds(3) })
    {
        string rawJson = await client.GetStringAsync(checkUrl + "?t=" + DateTime.UtcNow.Ticks);
        using var blacklistDoc = JsonDocument.Parse(rawJson);
        var revokedDict = blacklistDoc.RootElement.GetProperty("revoked_hwids");

        if (revokedDict.TryGetProperty(currentHwid, out var revokedInfo))
        {
            string reason = revokedInfo.GetProperty("reason").GetString();
            throw new Exception($"Máy tính đã bị thu hồi bản quyền! Lý do: {reason}");
        }
    }
}
catch (HttpRequestException)
{
    // Nếu mất mạng Internet hoặc GitHub tạm thời unreachable:
    // Vẫn cho phép tiếp tục sử dụng nếu chữ ký RSA offline hợp lệ!
}
